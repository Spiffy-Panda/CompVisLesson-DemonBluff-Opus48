Plan outline (rough)

Loose notes only — the detailed, cited version lives in the repo (plans/PLAN-pipeline.md, PROJECT-PITCH.md, research/RESEARCH.md).

Goal: read Demon Bluff game state from video frames only (no audio, no game files) and serve it over a REST API. Runs on a mid-grade gaming PC. The course is the real deliverable; the pipeline is the worked example.

Pipeline stages

0 · Frame selection. Don't process the whole hour of video. Cheap CPU cascade: low-stride decode → drop near-duplicate frames (perceptual hash) → gate "board vs. menu vs. modal". No runtime model.

1 · Localization. Find the cards by geometry, not a trained detector — the UI layout is stable (radial ring + numbered position badges) even when card art changes. Classical, fast, survives art swaps.

2 · Identification. Name each card with a small embedding + nearest-neighbor over a per-art reference gallery (re-fit by swapping reference images, no retraining), with the card's name-label text as an OCR cross-check.

3 · On-card reading. Tiny custom recognizer for the closed glyph set (role names, small numbers); general OCR only as a fallback / dev tool.

4 · State assembly. Merge per-card reads into one snapshot; smooth across frames (modals occlude the board, so single frames lie sometimes).

5 · REST service. FastAPI, models loaded once, versioned JSON snapshot with the resolution read from the media (never hard-coded).

Calls already made

  • Heavy models are dev-only; runtime models stay small (≈≤30M params) and train on a Titan XP / free Colab.
  • Card art is assumed swappable → every recognizer must be cheap to retrain.
  • Never bake in a resolution; never open the raw sample videos directly.
  • 44 roles + mechanics harvested from the wiki (cached locally, once).
  • Real footage has streamer overlays + occluding modals → robustness matters.

Still open

  • How much state to recover by tracking across frames vs. re-reading each frame.
  • Clarified: Minion and Twin Minion are functionally identical (treat as one recognition class); Puppet is spawned by the Puppeteer card, not dealt normally.
